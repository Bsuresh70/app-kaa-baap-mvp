# App Kaa Baap — MVP starter

A mobile-friendly static prototype for discovering apps by task, with country/price/platform filters and a small illustrative catalogue.

## Run locally
Open `index.html` in a browser. No build command is required.

## Deploy to Netlify
- Connect this GitHub repository to Netlify.
- Build command: leave blank.
- Publish directory: `.` (repository root).
- Deploy, then test search, filters, official links, and the developer form.

## Important limitations
- The catalogue is a starter sample, not a comprehensive or continuously verified global index.
- Search is keyword matching, not a live AI/LLM system.
- The developer form is a front-end demo only and does not submit or store data.
- Confirm app features, prices, platform support and availability from official sources before production.
- Do not put private API keys in browser-side files.
